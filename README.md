# Parking 2.0 Diagrams

Obsidian vault with the design docs and Mermaid diagrams for Parking 2.0.

## Contents

- `Parking 2.0 High Level Overview.md` – full system overview
- `High Level Overview Digestable.md` – condensed overview
- `Parking 2.0 ER Diagram.md` – data model
- `User Flow - *.md` – flows for the App User, Parker Web, Street Officer, Yard Officer and Control Room
- `Researched - Parking 2.0 Architecture and Plan.md` – existing Lahv+ backend and DB, new-service + shared-DB decision, `municipal` schema, monorepo, Figma → API map, Lahv+ app extension integration, roadmap, open decisions

## Usage

Open this folder as a vault in [Obsidian](https://obsidian.md). Diagrams are Mermaid and render in the editor preview.
